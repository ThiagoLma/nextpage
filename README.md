# Fyrn - Landing Page

Landing page moderna e responsiva para a agência de desenvolvimento web **Fyrn**.

## Stack

- HTML5
- CSS3 (Custom Properties, Animations, Transitions)
- JavaScript Vanilla (IntersectionObserver, Scroll Reveal)
- Google Fonts: Inter

## Funcionalidades

- Layout dark com acento em roxo elétrico
- Animações de scroll reveal
- Navbar com blur no scroll
- Menu hamburguer mobile
- Portfolio com overlay animado
- Timeline do processo de trabalho
- Totalmente responsivo (mobile-first)

## Como Usar

Abra o arquivo `fyrn.html` no navegador ou use um servidor local:

```bash
npx serve .
```
